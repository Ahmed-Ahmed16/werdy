# Triage labels

The skills speak in five triage roles. This file maps each role to the label string in werdy's tracker. werdy uses the defaults.

| Role in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The owner needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent to work on alone |
| `ready-for-human` | `ready-for-human` | Needs a person to implement it |
| `wontfix` | `wontfix` | Will not be done |

When a skill names a role, use the matching label from this table.
